## 一、历史观察范围

- Pipeline／PM：节点、边、PM 四表、异步图任务、审批入口与执行端 API。
- worker：调度、会话、离线报告、重启恢复、Gitea 与 worktree 处理。
- 多后端：OMP／Hermes／Codex 相关实现，历史入口按单个运行时后端组织。
- 图读取：服务端支持 depth 与单层截断；历史图界面同时请求 graph 与 topology，后者再次读取图。
- 登录：历史登录入口可生成 Logto 跳转地址。

## 二、S04：历史实现行为

| 行为范围 | 记录的可观察行为 | 对原生实现的要求 |
|---|---|---|
| 图读取 | 分层拉取、单层限制与边过滤 | 按层加载、分页和统一图响应 |
| 拓扑读取 | 先读取图再计算拓扑；历史界面同时请求图与拓扑 | 一次读取同时返回节点、边与拓扑摘要，避免重复全量查询 |
| 登录入口 | 登录入口生成 OIDC 跳转地址 | 完整回调、身份绑定、多组织与项目权限 |
| PM／节点身份 | 需求主记录、扩展元数据、节点与边的数据身份、层级与依赖 | 原生需求与图模型保留来源映射和历史关联 |
| 执行端运行时 | 单后端运行时入口、恢复注册顺序、离线报告与重启恢复 | 任务级后端路由、可核对恢复和过期报告拒绝 |
| 后端会话 | OMP／Hermes／Codex 的会话、进程与事件行为 | 统一适配器接口、原生 session 标识和事件记录 |

## 三、S05：历史图界面与会话轨迹行为

| 行为范围 | 记录的可观察行为 | 对原生实现的要求 |
|---|---|---|
| 图界面 | 页面同时请求 graph 与 topology，后者再次读取图 | 单次范围读取并复用拓扑摘要，不要求浏览器预载整图 |
| 会话事件 | 消息、工具调用与命令事件的类型和可观测信息 | 统一事件模型，区分实际执行与助手文字 |
