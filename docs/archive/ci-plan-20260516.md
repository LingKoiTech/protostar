## 实施步骤

### Phase 1：环境准备

1. **确认本机 Docker 环境**
   - 检查 Docker 是否运行
   - 确认本地镜像仓库地址（如 `registry.example.org` 或 `localhost:5000`）

2. **确认 Gitea Runner**
   - 检查 Gitea 实例是否启用 Actions
   - 注册或确认 Runner 状态
   - 配置 Runner 标签（如 `docker`, `flutter`）

### Phase 2：Flutter Web 构建配置

3. **创建构建脚本** `scripts/build_web.sh`
   ```bash
   #!/bin/bash
   # Flutter Web 构建脚本
   flutter clean
   flutter pub get
   flutter build web --release
   ```

4. **创建 Dockerfile** `Dockerfile.web`
   ```dockerfile
   # 使用 nginx 作为基础镜像托管 Flutter Web 资源
   FROM nginx:alpine
   COPY build/web /usr/share/nginx/html
   EXPOSE 80
   ```

### Phase 3：Gitea Actions 工作流

5. **创建工作流目录**
   ```bash
   mkdir -p .gitea/workflows
   ```

6. **编写 build.yml**
   - 触发条件：push to main/master
   - Job 1：构建 Flutter Web
     - 使用 Flutter Docker 镜像
     - 执行 `flutter build web --release`
   - Job 2：构建 Docker 镜像
     - 使用 Docker 镜像
     - 执行 `docker build -t qlp-client-web:latest .`
   - Job 3：推送镜像
     - 推送到本地仓库
     - `docker push <registry>/qlp-client-web:latest`

### Phase 4：验证与测试

7. **手动触发工作流**
   - 在 Gitea 仓库页面手动触发 Actions
   - 检查构建日志

8. **验证产物**
   - 检查 Docker 镜像是否生成
   - 检查镜像是否推送到仓库
   - 本地运行镜像验证功能

## 验证方式

1. **工作流验证**
   - Gitea Actions 页面显示绿色成功状态
   - 所有 Job 执行无错误

2. **产物验证**
   ```bash
   # 检查镜像是否存在
   docker images | grep qlp-client-web
   
   # 运行镜像测试
   docker run -d -p 8080:80 <registry>/qlp-client-web:latest
   curl http://localhost:8080
   ```

3. **自动化验证**
   - 修改代码并推送，触发自动构建
   - 确认新镜像自动生成并推送
